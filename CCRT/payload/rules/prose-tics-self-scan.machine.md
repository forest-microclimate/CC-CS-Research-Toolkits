# RULE: WHEN about to RETURN drafted / revised SCIENTIFIC prose for a HUMAN reader ⇒ FIRST run the writing-science detectors on your OWN draft, disposition every flag, THEN emit. The tic you are LEAST likely to catch is the one you just wrote (composing, you attend to meaning and believe your own sentences clean) ⇒ self-scan is symmetric: prose you WRITE gets the same scan as prose you review.
# ORIGIN: 2026-07-28, bad_writing_tics_register (BWT-001..009 — 9 recurring bad-writing tics in Claude-authored science prose). The strongest (cheap-cleverness flourish) was re-litigated across 3 separate conversations because the agent never scanned its OWN output. Cross-project prose discipline ⇒ global rules level (like root-before-bandaid). This is the ENFORCEMENT half of the writing-science skill's Framework 5 (transparency over performance): the flourish detector already existed; the missing piece was RUNNING it on your own draft.

RULE.self_scan_own_prose: prose you DRAFT or REVISE for a human reader is subject to every writing-science detector you would run on a user's draft, and is the prose you are LEAST likely to catch. WHEN about to hand back a rewritten paragraph / suggested sentence / drafted abstract ⇒ run the detectors on YOUR text, disposition the hits, THEN return it. Each detector is a CANDIDATE-flagger — YOU judge whether a flag is a real defect HERE; recast a real hit while PRESERVING the exact claim (never let the plain version assert more or less than the evidence supports). Per-tic checklist + fixes ⇒ REF writing-science skill (do not re-derive the detail here).

TICS (9; one line each by handle — full detection_signals + prevention_principle live in the writing-science skill):
  - cheap-cleverness / flourish (BWT-001): a clever construction (prop-triplet, witty reversal, showy metaphor) that makes the reader admire the sentence, not absorb the point ⇒ cut unless it delivers content the plain version would lose.
  - rule-of-threes / triadic-parallelism (BWT-002): 3+ consecutive clauses with identical openings ('does not X, does not Y, does not Z') — a cadence heard as performance ⇒ vary the connective or split.
  - abstruse / coined-notation (BWT-003): meaning packed into private notation / stacked modifiers ('Tension:limb (a)') a domain reader cannot decode ⇒ spell out / unpack on first use.
  - overclaim / overstatement (BWT-004): a finding phrased past the design — an absolute ('barely', 'never', 'first to', 'decoupled') the sample cannot carry ⇒ calibrate the quantifier (+ evidence-fit redirect, below).
  - code-metaphor / metaphor-leakage (BWT-005): a code/model idiom ('walk the link', 'foil', 'gate item', 'collapse') used figuratively in science prose, stranding a non-specialist ⇒ restate in the reader's own vocabulary.
  - reading-mannerism / mannerism-recurrence (BWT-006): a favored figurative verb — 'reading' a gradient/axis — leaned on as a tic ⇒ name the actual operation (measure/map/describe); + remove-every-instance, below.
  - over-de-jargon / jargon-over-correction (BWT-007): a de-jargon pass stripping field-standard terms / abbreviations as if 'unfamiliar to anyone' = jargon ⇒ triage first (+ target-reader default, below).
  - empty-amplifier / degree-word-filler (BWT-008): a degree word ('even', 'sharply') adding emphasis the sentence has not earned ⇒ delete unless it changes the factual content ('even' is context-dependent — keep only for a genuine against-expectation surprise).
  - false-antithesis / preemptive-apology (BWT-009): a purposeful design choice framed as a concession ('X rather than Y'), reading as an apology ⇒ state the positive decision.

RULE.remove_every_instance (BWT-006): WHEN a mannerism / tic is flagged ⇒ remove EVERY instance across the WHOLE draft, not only the quoted one. A single-draft scan misses cross-draft recurrence (origin case: 'reading' flagged in one draft, found UNCHANGED in a later one) ⇒ fix the CLASS, not the instance.

RULE.target_reader_default (BWT-003 + BWT-007 — a calibration PAIR): the default target reader is a DOMAIN SCIENTIST — NOT a programmer / modeler / general audience. Calibrate de-jargoning to that venue: genuine jargon a domain reader would not know ⇒ define/replace; a field-standard term the reader expects (e.g. Sørensen turnover) ⇒ KEEP; an unexpanded abbreviation (e.g. β_sim) ⇒ spell out on first use. De-abstruse (BWT-003) WITHOUT over-stripping field terms (BWT-007); the pair fails if either half fires alone.

RULE.evidence_fit_redirect (BWT-004): you own only the WORDING of an overclaim. WHETHER the design/sample supports an absolute is a CONTENT judgment ⇒ redirect it to the formal-argument-checker agent. Flag the surface absolute + recast the wording yourself; hand the evidence-fit adjudication off — do NOT rule on design you do not own, and do NOT leave the absolute unflagged.

CAVEAT (LLM limits): no reliable introspection ⇒ this rule REDUCES, NOT eliminates, the tics, and only when LOADED and the detectors are actually RUN on your own draft (the belief 'my prose is clean' IS the failure). The mechanical layer is a script you RUN, not a habit you recall — hence the trigger is the output-detectable moment (about-to-return-drafted-prose), not an exhortation to 'write plainly'.
